# System Requirements

## Functional requirements

- User registration and login
- JWT-based authentication
- Role-based authorization
- Patient profile management
- Doctor management
- Appointment booking and queue handling
- Medical records and vital logs
- Lab booking and result release
- Prescriptions and pharmacy workflow
- Billing, payments, refunds, insurance
- Notifications and alerts
- Audit logging
- AI-assisted heart risk and report reading

## Non-functional requirements

- Secure authentication
- Role-based access control
- Responsive UI
- API-based architecture
- Scalable deployment support
- Background task processing
- Monitoring and backup support
