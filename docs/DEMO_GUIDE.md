# Demo Guide

## Demo order

1. Login with role-based user
2. Open dashboard
3. Show patient list and patient detail
4. Create or view appointment
5. Show notification center
6. Show billing/payment flow
7. Show lab result/report
8. Show prescription PDF
9. Show audit logs or system health
10. Show Swagger docs and deployment setup

## Demo talking points

- custom user roles
- JWT authentication with refresh flow
- 2FA support
- modular Django backend
- Next.js frontend
- Celery + Redis background support
- PostgreSQL + Docker deployment
- AI/ML health features
